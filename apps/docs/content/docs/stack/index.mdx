Purse decides and keeps the record. It does not hold keys, move money, or run an
indexer. Three services do those.

## What each one is for

| Service   | Does                                      | Purse never           |
| --------- | ----------------------------------------- | --------------------- |
| Privy     | Holds every wallet and signs when told to | Sees a private key    |
| Hedera    | Settles the payment in stablecoin         | Submits a transaction |
| The Graph | Records transfers and prices them         | Runs its own indexer  |

## What removing one would cost

| Without   | What stops working                                                 |
| --------- | ------------------------------------------------------------------ |
| Privy     | Nothing can sign. Purse holds no keys and has no way to get one.   |
| Hedera    | Nothing settles. Decisions still happen, but no money moves.       |
| The Graph | Dollar limits refuse rather than guess. Token limits keep working. |

The third row is worth reading twice. Losing the price feed does not quietly
degrade into estimating. It refuses, because a limit set in dollars means
dollars matter.
